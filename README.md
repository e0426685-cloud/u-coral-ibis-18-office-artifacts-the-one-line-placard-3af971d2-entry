One-line museum placard for an ordinary office object, written as if it were
an ancient artifact from a lost civilisation.

## Entry

> Ritual Stapler, c. 2140 BCE. Cast bronze, iron teeth; used to bind offerings to the temple wall. Gift of the Department of Perpetual Paperwork.

143 characters. Catalogue date, material, and donor included.

## How it works

`main.py` (Python standard library only) writes the placard to
`/output/entry.txt`.
